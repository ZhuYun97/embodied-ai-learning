## TL;DR

τ0-WM(tau-zero world model)是 **2026-05-31 发布的开源预训练具身世界模型**,由 **上海创智学院副教授、智元机器人首席科学家罗剑岚** 带队。团队称其为"全球最大规模的开源预训练具身世界模型":**5B 参数**、**约 3 万小时预训练数据**(真机遥操作 17,800h + UMI 6,500h + 人类第一视角 3,000h)⚠️。其特点不在"端到端一次出动作",而在**推理时算力(test-time computation)**:用一个「**提议 → 推演 → 评估修正**」三步回路,先由视频-动作模型采样多组候选动作,再由动作条件视频模拟器为每组候选**推演多视角未来画面**,最后以 RCS 打分 + LAR 修正**选出最优动作**再执行。团队报告四项长程精细操作任务平均成功率超过对标方案(如 Pen→Box 从 30% 提升至 50%)⚠️。本页定量均为团队自评(经媒体报道转述),缩写全称与基准口径**待核**。

## 一、定位与动机

τ0-WM 把世界模型当作**推理时的"预演 + 评估"引擎**,而非仅仅训练期先验:既然世界模型能"想象动作的后果",那就让机器人在**执行前**对多个候选动作各自预演未来、再择优执行——把更多算力花在推理时(test-time compute),换取更稳的长程精细操作。

它在本站 WAM 谱系中是一个**偏"模型预测控制(MPC)/测试时搜索"**的形态:有一个动作提议器,也有一个动作条件的视频世界模型作评估器,二者在推理回路里协作。这既不同于级联式"先生成整段未来视频、再一次性抽动作"(如 [UniPi](/wam/papers/unipi)),也不同于联合式"一个前向同生未来与动作"(如 [DreamZero](/wam/papers/dreamzero));它更像"提议-想象-打分"的闭环搜索。**注**:综述 [arXiv:2605.12090](/wam/)(2026-05-12)发布于 τ0-WM 之前,未收录本工作,故其在综述 Cascaded/Joint 分类中的确切归属**待核**。

机构与谱系:τ0-WM 出自 **智元(AgiBot,项目页 finch.agibot.com)/ 上海创智学院(sii-research)**,与本站 [GO-1](/vla/papers/go-1)、WAM 细读 [Genie Envisioner](/wam/papers/genie-envisioner) 同属智元系——是智元在"世界模型作策略/评估"方向的又一工作。

## 二、方法与架构:提议 → 推演 → 评估修正

团队披露的三步推理流程(据报道逐字转述):

1. **提议(Propose)**:"视频动作模型根据当前多视角观测、语言指令以及机器人状态,**一次性采样出多组候选动作**"。
2. **推演(Imagine)**:"**动作条件视频模拟器**会针对每组候选动作,进一步生成对应的**多视角未来画面**"——即对每个候选"在脑内跑一遍"看后果。
3. **评估修正(Evaluate & Correct)**:通过 **RCS 打分** 与 **LAR 修正** 机制选优;结合 **Test-Time Computation**,让机器人"在执行前对多个候选动作进行排序,选出最优方案"。

> RCS、LAR 的英文全称与具体定义,报道未展开(**待核**);提议器与视频模拟器是否共享主干、动作如何最终下发、打分器如何训练等实现细节亦**待核**,以一手论文 / GitHub `sii-research/tau-0-wm` 为准。

**规模(团队自评 ⚠️)**:参数 **5B**;预训练数据 **约 3 万小时**,构成为真机遥操作 **17,800h** + UMI **6,500h** + 人类第一视角 **3,000h**——团队称是"目前全球开源预训练具身世界模型中最大的"。其数据生态(真机 / UMI / 人类视频)恰好对应本站 [具身数据全景](/vla/papers/embodied-data) 与 WAM 综述的四类数据来源。

## 三、实验与关键结果

以下为**团队自评(经媒体报道转述)⚠️**,尚无基准维护方统一第三方评测,缺口标「待核」。

| 维度 | 结果(团队自评 ⚠️) |
|---|---|
| 长程精细操作(四项任务) | 平均成功率超过对标方案(对标对象、绝对数值待核) |
| 新任务示例 Pen→Box | 相比基线由 30% 提升至 50% |
| 参数 / 预训练数据 | 5B / ~3 万小时(真机 17.8k + UMI 6.5k + 人类 3k 小时) |
| 统一基准成绩 | 待核(报道未给出标准基准如 LIBERO/RoboTwin 的成绩) |

要点:τ0-WM 的卖点是**用推理时算力换性能**——通过"想象多个未来再择优",在长程、需要时序一致的精细操作上更稳;Pen→Box 30%→50% 是报道给出的唯一具体数字(团队自评 ⚠️),其余为定性"超过对标"。

## 四、与本站谱系的关系

- **智元系**:与 [GO-1](/vla/papers/go-1)、[Genie Envisioner](/wam/papers/genie-envisioner) 同出智元(AgiBot),是智元在世界模型方向的延伸。
- **机制对读**:τ0-WM 的"动作条件视频模拟器 + 候选评估"与 [Genie Envisioner](/wam/papers/genie-envisioner) 的 GE-Sim(动作条件神经仿真器)思路相通,但 τ0-WM 把仿真器直接嵌进**推理时的动作择优回路**;其"想象未来再选动作"与 [DreamZero](/wam/papers/dreamzero)"预演未来再反推动作"同源而手法不同(τ0-WM 走显式的多候选搜索 + 打分)。
- **开源定位**:与多数闭源旗舰(GR00T N2 等)不同,τ0-WM **开源权重 + 代码**(GitHub/HF `sii-research/tau-0-wm`),便于复现。

## 五、局限与存疑

- **来源为媒体报道**:本页主要据 2026-05-31 的中文媒体报道转述团队发布内容,**非一手论文逐字**;5B、3 万小时、Pen→Box 30%→50% 等均为团队自评(⚠️),应回到 GitHub/项目页/论文核实。

- **方法细节缺口**:RCS/LAR 全称与定义、提议器与模拟器的架构关系、test-time 候选数与时延代价等均**待核**。
