# 🧠 具身大脑公司分档榜

> 只评「**具身大脑**」——具身智能的**认知/模型层**(视觉-语言-动作模型 VLA、机器人基础模型、世界模型、泛化操作策略),**机器人本体硬件不计分**。
> 本页为 **2026-06-08 快照**,经多源检索 + 对抗式事实核验整理(逐条 2/3 票核验)。型号迭代极快,数据会过时。

::: info 怎么读这张榜(方法与口径)
- **不硬排 1-N,只分档**。私有公司大量数据自报,强行排名次会制造伪精确。
- **档位 = 用一手源能验证多少大脑层证据的宽度**,不是估值或市场地位。同档内不排名次。
- 评分看 5 维:**①模型技术(公开 benchmark / 技术报告 / 可下载权重)· ②融资资本 · ③真实落地 · ④团队履历 · ⑤开源与生态**。
- **可信度体例**:✅ = 经核查 / 一手可下载(权重、数据集、招股书、多源融资);⚠️ = 提出方/厂商自评(benchmark 分数、估值、订单、"首个/最强");**待核** = 仅单一来源、未交叉验证。**查不到就如实留空,不编造。**
- 右侧「⚠️/待核 存疑」列在全站**可信度透镜**下会被暗化——点顶栏透镜开关可只看已核证据。
:::

**档位含义**:`T0` 前沿(已验证旗舰模型 + 强信号 + 可信团队)· `T1` 强实力(有可验证模型但范围窄/证据薄,或资本极强但模型公开证据有限)· `T2` 可信进入者 · `—` 无自研大脑、不予定档。

## 🔍 本轮核验拆穿/修正的关键「水分」

这些是检索中流传、但经对抗式核验**被推翻或需打折**的说法——引用时务必小心:

1. **Tesla 部署**:自媒体传「2026 年 1 月已部署 1000+ 台 Gen3 在工厂工作」——**Musk 本人在 Q4 财报会(2026-01)否认**,称 Optimus 仍处 R&D、工厂「无实质使用」,实际约数百台。
2. **「中国公司 RoboArena 击败英伟达」**:被 NVIDIA(Joel Jang / 官博)公开反驳;且千寻对标的两个头名(Cosmos3-Nano、DreamZero)**其实都是英伟达的**;1924 等分数除公司公告外**无独立复核**,RoboArena 论文本身也不含这些分数。
3. **1X 世界模型角色**:14B 的 1XWM 在官方报告里**主要是「离线评估器/策略打分器」**,不是实时驱动 NEO 的策略;NEO 发布演示被 WSJ 揭露 100% 远程遥操。
4. **智平方 benchmark**:「FiS-VLA 综合性能超 π0 达 30%」是营销数字,**论文实测仅 +14%**;「GOVLA 首提全身控制」也不成立(Figure Helix 更早)。
5. **Generalist**:GEN-1 的 99% 成功率 / 3 倍速全是自评博客,The Robot Report 明确「无独立第三方验证」。
6. **Apptronik**:$53 亿估值的明星公司**不自研大脑**——Apollo 的 VLA 由 Google DeepMind(Gemini Robotics)提供。
7. **智元 GO-1**:「+30% 超 Open-X-Embodiment」一句经核验 **0-3 被否决**,不应引用该具体数字(GO-1 与开源数据集本身真实)。

## 📊 第三方真机榜单:目前唯一能横比的一点

跨厂「谁的大脑最强」**目前没有各方都认的硬榜**——所有 benchmark「第一」几乎都是厂商自己跑的、口径不同、不能硬比。最接近中立的两个机制:

- **RoboChallenge Table30**(桌面真机,独立运营):千寻 Spirit v1.5 **66.09**(成功率 50.33%) > 自变量 WALL-OSS **54.69** > π0.5 …;Dexmal DM0 自报 62.0% 但跑在**它自家运营**的实例上。
- **RoboArena**(双盲众包真机,NVIDIA / Stanford / Berkeley 合著,arXiv 2506.18123):机制最中立,但 2026-06「谁第一」陷入**英伟达 vs 千寻互相宣称、无中立裁定**。
- → 能确认的是:上面这几家已进入「**开源权重 + 真机评测**」的同一梯队;具体名次仍待独立复核。

## ⚠️ 方法与局限 · 数据缺口

- 共 **19 家**(海外 9 / 国内 10)。「档位」只反映**大脑层证据的可验证度**,非估值或市场地位。
- **可硬核实的「地基」(✅)** 只有几类:开源数据集计数(AgiBot 100 万条、SynGrasp 十亿帧)、开源权重/license(openpi、GR00T、WALL-OSS、DM0、Spirit v1.5)、顶会收录(VPP/RoboMamba/FiS-VLA)、融资轮次/投资方(多源)。档位主要靠这些撑,**不是靠 benchmark 分**。
- **所有「benchmark 最强 / 超 SOTA」= 厂商自报(⚠️),禁止跨厂硬比**;**所有估值都是私募 post-money、轮次自报**。
- `insufficient-data ≠ 弱`:Apptronik 资本/落地很强,只是大脑非自研。
- **仍待补的缺口**:Boston Dynamics、优必选(本体为主)、跨维智能、逐际动力;银河通用与智元的**精确融资额**;海外(Figure 之外)的落地硬数据。
- **时效**:数据跨 2024-09 ~ 2026-06,后继型号(GR00T N1.5+、Gemini Robotics-ER 1.6 等)已出,不推翻已验证发布,但本榜是**快照**。
