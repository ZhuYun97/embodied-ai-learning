# 🏆 具身大脑公司分档榜

> 只评**具身大脑**(认知/模型层:VLA / 世界模型 / 基础模型,**硬件本体不计分**)· **2026-07-01 快照**,多源检索 + 对抗式核验。完整方法与档位定义见下方折叠的「怎么读这张榜」。

::: details 怎么读这张榜(方法与口径)— 点击展开
- **不硬排 1-N,只分档**。私有公司大量数据自报,强行排名次会制造伪精确。
- **档位 = 用一手源能验证多少大脑层证据的宽度**,不是估值或市场地位。同档内不排名次。
- 评分看 5 维:**①模型技术(公开 benchmark / 技术报告 / 可下载权重)· ②融资资本 · ③真实落地 · ④团队履历 · ⑤开源与生态**。
- **可信度体例**:✅ = 经核查 / 一手可下载(权重、数据集、招股书、多源融资);⚠️ = 提出方/厂商自评(benchmark 分数、估值、订单、"首个/最强");**待核** = 仅单一来源、未交叉验证。**查不到就如实留空,不编造。**
- 右侧「⚠️/待核 存疑」列在全站**可信度透镜**下会被暗化——点顶栏透镜开关可只看已核证据。
:::

## 🔍 核验拆穿/修正的关键「水分」

检索中流传、但经对抗式核验**被推翻或需打折**的说法——引用时务必小心:

1. **Tesla 部署**:自媒体传「2026 年 1 月已部署 1000+ 台」——**Musk 本人在 Q4 财报会否认**,称工厂「无实质使用」,实际约数百台。

5. **灵初 Psibot**:「Psi-R2 在 MolmoSpaces 全球第一、胜 PI/NVIDIA」仅来自**自家直播**,AllenAI 官方榜无此条目 → 待核。

7. **跨维智能**:「零样本超 SOTA / 99.9% 成功率」是论文自报+营销,**同组另一篇 arXiv(2603.22876)反证**真实世界 VLA 成功率仅 11.5–64.6%。
8. **智平方**:「FiS-VLA 超 π0 达 30%」是营销数字,论文实测仅 **+14%**;「GOVLA 首提全身控制」不成立(Figure Helix 更早)。
9. **智元 GO-1**:「+30% 超 Open-X-Embodiment」一句经核验 **0-3 被否决**,不应引用该具体数字。

## 📊 第三方真机榜单(目前唯一能横比的一点)

跨厂「谁的大脑最强」**目前没有各方都认的硬榜**——所有 benchmark「第一」几乎都是厂商自己跑的、口径不同、不能硬比。最接近中立的两个机制:

- **RoboChallenge Table30**(桌面真机,**Dexmal 运营**——对 Dexmal 自家模型不构成第三方,对其它公司算最接近中立的真机横比):**2026-06-10 官方 API 实查 v1 榜**:Era0(星动纪元)**76.34 / 64.3% 第 1 → T0** > DM0(Dexmal,自家榜)72.25 / 62.0% 第 2 → T1(自家榜) > GigaBrain-0.1(极佳)**68.34 / 51.7% 第 3 → T0** > Spirit-v1.5(千寻)**67.19 / 51.0% 第 4 → T0**(持续前三) > π0.5 基线 61.84 / 42.7% > … > wall-oss-v0.1(自变量)55.30 / 35.3% **约第 9 → T1**(低于基线)。本站 2026-06-08 快照曾为「千寻 66.09 第一 > 自变量 54.69 第二」——**榜面随提交快速变动,引用必须带时间戳**。
- **RoboArena**(双盲众包真机,NVIDIA / Stanford / Berkeley 合著,arXiv 2506.18123):机制最中立,但 2026-06「谁第一」陷入**英伟达 vs 千寻互相宣称、无中立裁定**。
- → 能确认的是:**星动纪元(第1)、极佳(第3)、千寻(第4 持续前三)**已进入「**开源权重 + 真机评测持续前三**」梯队,构成 T0 独立背书;Dexmal(第2)虽优秀但自家榜不算第三方;自变量虽开源但性能低于基线,技术实力存疑。

## ⚠️ 方法与局限 · 数据缺口

- 共 **43 个主体**:独立公司 31(国内 17 / 海外 14)+ **大厂内部具身部门 12**(🏢 标注,已融入上面两榜);其中 **T0 共 9 个**(国内 5 / 海外 4),**全部为独立公司**——12 家大厂部门经按同一严格口径重核,**无一达 T0**(原列 T0 的字节、阿里已降 T1,详见国内榜下注)。「档位」只反映**大脑层证据的可验证度**,非估值或市场地位。
- **T0 的门槛(2026-07 借鉴外部视角后平衡)**:旗舰模型须有**持续的独立背书**——顶会同行评审、或里程碑级被业界使用的开源资产、或第三方真机榜**持续前三**(非单次登顶)、或**真实客户 + 学术背书组合**;自变量因低于基线保持 T1。「有开源模型 + 巨额融资但 benchmark 自评」归 **T1**(国内此类公司密集,故 T1 偏大)。
- **可硬核实的「地基」(✅)** 只有几类:开源数据集计数、开源权重/license(openpi、GR00T、WALL-OSS、DM0、Spirit v1.5、G0、Thinker-4B、AgiBot World、GigaBrain 等)、顶会收录(VPP/RoboMamba/FiS-VLA/Sim2Real-VLA/DexGraspVLA 等)、融资轮次/投资方(多源)、真实客户(宁德时代/李飞飞团队/NVIDIA/PI 等)。
- **所有「benchmark 最强 / 超 SOTA」= 厂商自报(⚠️),禁止跨厂硬比**;**所有估值都是私募 post-money、轮次自报**。
- **仍待补的缺口**:帕西尼 PaXini、智源 RoboBrain(研究机构)、星尘智能、自动驾驶向 VLA(Wayve 等,口径外);银河通用与智元的**精确融资额**;多数公司的落地硬数据(订单/付费客户多为自报)。
- **时效**:数据跨 2024–2026-07,后继型号迭代很快,本榜是**快照**。
