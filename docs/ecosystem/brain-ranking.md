# 🧠 具身大脑公司分档榜

> 只评「**具身大脑**」——具身智能的**认知/模型层**(视觉-语言-动作模型 VLA、机器人基础模型、世界模型、泛化操作策略),**机器人本体硬件不计分**。
> 本页为 **2026-06-08 快照**,经多源检索 + 对抗式事实核验整理(逐条 2/3 票核验)。型号迭代极快,数据会过时。

## 🔍 核验拆穿/修正的关键「水分」

检索中流传、但经对抗式核验**被推翻或需打折**的说法——引用时务必小心:

1. **Tesla 部署**:自媒体传「2026 年 1 月已部署 1000+ 台」——**Musk 本人在 Q4 财报会否认**,称工厂「无实质使用」,实际约数百台。
2. **「中国公司 RoboArena 击败英伟达」**(千寻):被 NVIDIA 公开反驳;且对标的两个头名(Cosmos3-Nano、DreamZero)**其实都是英伟达的**;分数除公司公告外**无独立复核**。
3. **Boston Dynamics**:流传「Atlas LBM 已发 Science Robotics」——核验为误,实为 **arXiv 预印本(2507.05331)**,且实验体是双臂 Franka 非 Atlas;Atlas 大脑依赖 TRI + Google DeepMind 合作、**非自研**。
4. **Covariant**:「$75M 为 Series D」错(是追加 Series C);「早期天使含贝索斯/盖茨」**张冠李戴**(实为 Hinton/LeCun/李飞飞等);且 2024-08 核心团队已被亚马逊招走、公司近乎停摆。
5. **灵初 Psibot**:「Psi-R2 在 MolmoSpaces 全球第一、胜 PI/NVIDIA」仅来自**自家直播**,AllenAI 官方榜无此条目 → 待核。
6. **戴盟 / 帕西尼混淆**:网上两篇 VTLA / OmniVTLA arXiv 论文常被安到戴盟头上——实为**中科院自动化所/三星/智源** 与 **帕西尼/上交** 出品,与戴盟无署名关联。
7. **跨维智能**:「零样本超 SOTA / 99.9% 成功率」是论文自报+营销,**同组另一篇 arXiv(2603.22876)反证**真实世界 VLA 成功率仅 11.5–64.6%。
8. **智平方**:「FiS-VLA 超 π0 达 30%」是营销数字,论文实测仅 **+14%**;「GOVLA 首提全身控制」不成立(Figure Helix 更早)。
9. **智元 GO-1**:「+30% 超 Open-X-Embodiment」一句经核验 **0-3 被否决**,不应引用该具体数字。

## 📊 第三方真机榜单(目前唯一能横比的一点)

跨厂「谁的大脑最强」**目前没有各方都认的硬榜**——所有 benchmark「第一」几乎都是厂商自己跑的、口径不同、不能硬比。最接近中立的两个机制:

- **RoboChallenge Table30**(桌面真机,独立运营):千寻 Spirit v1.5 **66.09**(成功率 50.33%) > 自变量 WALL-OSS **54.69** > π0.5 …;Dexmal DM0 自报 62.0% 但跑在**它自家运营**的实例上。
- **RoboArena**(双盲众包真机,NVIDIA / Stanford / Berkeley 合著,arXiv 2506.18123):机制最中立,但 2026-06「谁第一」陷入**英伟达 vs 千寻互相宣称、无中立裁定**。
- → 能确认的是:上面这几家已进入「**开源权重 + 真机评测**」的同一梯队;具体名次仍待独立复核。

- *来源:UPenn PAL Lab(penn-pal-lab.github.io)· arXiv 2606.04233 / 2510.13626 · The Next Web、SCMP(2026-06)。*

## ⚠️ 方法与局限 · 数据缺口

- 共 **33 家**(国内 17 / 海外 16),其中 **T0 仅 7 家**(国内 3 / 海外 4)。「档位」只反映**大脑层证据的可验证度**,非估值或市场地位。
- **T0 的门槛(2026-06 收紧)**:旗舰模型须有**独立背书**——顶会同行评审、或里程碑级被业界使用的开源资产、或第三方真机榜第一;「有开源模型 + 巨额融资但 benchmark 自评」归 **T1**(国内此类公司密集,故 T1 偏大)。
- **可硬核实的「地基」(✅)** 只有几类:开源数据集计数、开源权重/license(openpi、GR00T、WALL-OSS、DM0、Spirit v1.5、G0、Thinker-4B、AgiBot World 等)、顶会收录(VPP/RoboMamba/FiS-VLA/Sim2Real-VLA/DexGraspVLA 等)、融资轮次/投资方(多源)。
- **所有「benchmark 最强 / 超 SOTA」= 厂商自报(⚠️),禁止跨厂硬比**;**所有估值都是私募 post-money、轮次自报**。
- `insufficient-data(—)≠ 弱`:Apptronik / Sanctuary 资本不弱,只是大脑非自研或零公开证据。
- **仍待补的缺口**:帕西尼 PaXini、智源 RoboBrain(研究机构)、星尘智能、自动驾驶向 VLA(Wayve 等,口径外);银河通用与智元的**精确融资额**;多数公司的落地硬数据(订单/付费客户多为自报)。
- **时效**:数据跨 2024–2026-06,后继型号迭代很快,本榜是**快照**。
